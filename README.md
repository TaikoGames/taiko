# Taiko

Static marketing site for **Taiko Games**, a full-cycle game art studio. Built as a
plain HTML/CSS/JS site, ready to host on GitHub Pages.

## Structure

```
index.html      # single-page site
css/style.css   # styles (dark game-studio theme)
js/main.js      # mobile nav + footer year
```

## Run locally

Just open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000

## Deploy (later)

Push to GitHub and enable **Settings → Pages → Deploy from branch → `main` / root**.

## Notes

The layout and section structure are inspired by game-art-studio sites; all copy,
branding, and placeholder art here are original. Swap in your real projects, logos,
and images when ready.
